## 1. 验收 A：事件/投影/applied_seq 同事务；projector 抛错全回滚；Bus 收不到未提交事件

（`doc/PHASE1-SLIM.md` L69 / `doc/plans/r1-slices.md` L15）

- **同事务**：`txn.py` `_commit_sequence` L401-476 在**单个**写事务内执行 §3.2 五步序列；`_insert_and_project` L623-659 先 INSERT events 行（L641）、再对每个事件调 `projector.apply`（L656-657，投影 sessions/messages/applied_seq 于同一连接）；提交前重验 A=H+n（`_commit_sequence` L461-476）。`projector.py`：`_project_created` L111-135（INSERT sessions 行含 applied_seq）、`_project_prompt` L137-172（INSERT messages 行 + `_set_active_run_id` + `_advance_applied_seq` L200-206，§7 L316 同事务置 active_run_id）。schema 侧 events 无 FK、创建 session 与首条事件同事务（`0001_initial.py` 模块注记 + `doc/CORE-CONTRACTS.md` L183）。
- **projector 抛错 → 全回滚**：`txn.py` `_commit_transaction` L333-343 对任何 `BaseException` rollback 整个事务。测试：`test_store_commit.py::test_commit_projector_failure_rolls_back_entirely`（注入抛错 fake projector → 零 events 行 → 重试干净成功）；`test_projector.py::test_projector_failure_rolls_back_and_retry_restarts_seq`（真 projector + SQL 损坏重放）；`test_projector.py::test_projector_missing_advance_is_caught_by_store_recheck`（故障注入：恰好跳过 applied_seq 推进 → store 的 A=H+n 复核拦截回滚）；`test_store_commit.py::test_commit_applied_seq_mismatch_isolates_and_gates`（A≠H 已存态 → StorageCorrupt + 隔离）。
