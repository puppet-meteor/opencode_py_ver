- **c Last-Event-ID 编码**：头缺席=cursor None（seq 0 全量重放）；在场=`"{session_id}:{seq}"`（rsplit(':',1) 解析）。畸形（无冒号/非整数/负数）→**传输层** `_TransportError` 400+CoreError{InvalidCursor, retryable=false}；**跨 session**（解析 session_id≠路径 session_id）→同形 400；**超前**（seq>连接时 H——follow `__aenter__` 亲抛 InvalidCursorError）→既有 `_store_error_handler` 400 **不空等**。头读取经 starlette 归一形（h11 恒小写=054 顺手项在录）。
- **d SSE 帧形**：事件帧=`id: {session_id}:{seq}`+`event: {type}`+`data: {DurableEvent 8 字段 model_dump(mode=json) 紧凑 JSON}`（envelope 内 `evt_` id=client 去重键）；`Synced` 标记→**注释行** `: synced {H}`（零 id 零 event——不推进 Last-Event-ID）；keepalive→`: keepalive` 每 `SSE_KEEPALIVE_SECONDS=15.0`（模块常量+`__anext__` 超时包裹形；测试 patch 常量加速）。id 单调递增（follow ④继承）。
- **e 断线补读+去重**：服务端恒从给定 cursor 严格后放（follow 语义——**重连零服务端重叠**）；client 按 data 内 `evt_` id 去重（测试钉 id 单调+envelope 含 evt_ id）；**首版不回放 ephemeral**（L248——durable-only，Bus 预览面不在本票）。
- **f 慢消费者（L108 句+054 上浮①收口）**：**pull 模型钉死**——follow 生成器内联迭代于响应流（**禁预取任务/禁无界队列**）；慢客户端=send 挂起=生成器挂起=零服务端内存增长；runner 零阻塞（bus=信号非数据面——eventlog.py `_drain` docstring 亲证）。测试证：慢读流（send 逐块延迟）同时 prompt→run 至终态 succeeded。**SlowConsumer 语义二分定谳**：SSE 面慢消费者=容忍非错误；429 SlowConsumer=连接容量拒绝专用（请求槽+流槽两预算）——语义不冲突，注记在录。
- **g 流并发预算**：SSE 流**不占** MAX_CONCURRENT_REQUESTS 8 槽（middleware 全生命持槽现状=8 流即饿死请求面）；新模块常量 `MAX_CONCURRENT_SSE_STREAMS=8`+middleware 对 events 路径独立计数（GET+path `/session/.../events` 匹配——纯 ASGI 同步序无锁论证同 054；检查序=401→403→429）；超→429 CoreError{SlowConsumer, retryable=true}。测试：8 流悬挂+第 9 流 429+请求面同态仍服务（两预算独立性亲证）。
- **h 限额面**：MAX_RESPONSE_BYTES 4 MiB **不作用于流聚合**（SSE=无界流——与 054 单体 JSON 响应语义二分，注记在录）；**帧级**上限：单事件帧序列化>4 MiB→错误帧 CoreError{ValidationError, retryable=false}+关流；请求体限额不适用（GET 无 body）。新常量模块级+测试钉死。
