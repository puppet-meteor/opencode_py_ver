【任务】
1. `src/opencode/bus/bus.py`：`VolatileBus`——
   - `subscribe(session_id, types?) -> AsyncContextManager[AsyncIterator[Event]]`（契约 L219 字面）：进入订阅后的 live 通知才可见（含 ephemeral/committed durable）；类型过滤（types? 参数）；队列**有界**（上限值自定，选值+理由写进度文件——TS `PubSub.unbounded`（bus.ts L199）→Python 有界+SlowConsumer 是契约 §4 明文差异）；溢出断开订阅并报 `SlowConsumer`（CoreErrorCode.SLOW_CONSUMER），**不静默丢 durable**；退出 context 注销订阅并释放队列。
   - 通知面（对齐 TS `notify` bus.ts L496-509：listeners→live PubSub→typed 顺序）：按 seq 顺序投递已提交 durable 事件+ephemeral 事件；同一 notify 调用内不重复投递。**Bus 不持久任何状态**（无 durable cursor/无重放——重放归 S6 EventLog；"遗漏通知由 EventLog 补读"是组合层/S6 职责）。
   - `Event` 投递类型：contracts 无统一 Event 别名——在 bus 模块定义 `DurableEvent | EphemeralEvent` union 别名（或等价方案），文档化；typed 事件定义可经 `EventRegistry`（S1 已交付）校验。
   - **Python 差异（r1-slices L116）**：无 location 路由（bus.ts L729-749 `local()`/routes 不做）、无 deprecated listen/project。
2. **通知归组合层**（§3.2 L159 步 5 的 Python 落法，S3 既定）：store/txn 保持 bus-free；"commit 成功→按 seq 通知"由调用方组合（S7 SessionService 定式"状态门禁→生成事件→commit→本地通知"；本切片以集成联测组合该模式验证契约语义）。Bus 本体**零 DB 依赖注入**（验收 A 后半）。
3. `tests/contract/test_bus.py`（纯 asyncio 单测，无 DB，r1-slices L119 测试计划）：订阅时机（订阅前事件不可见）、队列上限→SlowConsumer（溢出断开不静默丢）、context 退出后注销（发布不再入队）、类型过滤、注销后队列释放。
4. `tests/integration/test_bus_commit.py`（真实 SQLite+alembic 建库+SessionStore+SessionProjector+VolatileBus 组合联测）：订阅→**commit 失败**（注入抛错 projector，对齐 S4 FailingProjector 模式）→订阅者零事件、库零残留；换健康 projector **commit 成功**（同批 seq 重起）→按 seq 收到 committed durable 通知——**Bus 收不到未提交事件**（验收 A 后半）。
