【任务】
1. `src/opencode/bus/eventlog.py`：
   - `EventCursor = {session_id: str, seq: int >= 0}`（0=日志之前）；`EventPage = {items: list[DurableEvent], next_cursor: EventCursor, has_more: bool}`；`Synced(cursor)` marker 与 `LogItem = DurableEvent | Synced`（TS `log.synced` L879-884 对应）。
   - `EventLog.read(session_id, after: EventCursor | None, limit=100) -> EventPage`（契约 L224-227 字面）：seq>after.seq 的 durable；None=本 session seq=0；limit 1–1000（越界**钳制**到界内——r1-slices L132"limit 钳制"）；next_cursor=最后一个 items 的 seq，空页保持输入 cursor；**未建 session 报 NotFound**；**InvalidCursor** 三类=cursor.session_id 与请求不符/seq 为负/seq 超过当前高水位 H——明确报错不空等；**H=已提交日志水位 MAX(events.seq)，不用投影水位 applied_seq**。
   - **坏页语义（T-A-002 终裁，逐项落实，契约 L227）**：按原 seq 连续解码 type+version；未知版本/类型与损坏数据 **fail closed 不跳过**（TS L809-827 跳过并前进 raw seq 的行为**不沿用**）——坏页**整页 StorageCorrupt(retryable=false)**，不返半页、不推进 next_cursor（失败后同 cursor 重试仍同错）；read 失败时 cursor=输入 after（None 为 0）；follow 遇坏页=已 yield 的健康事件保留，随后抛 StorageCorrupt 终止、退出注销 wakeup，**不发越过坏点的 Synced**；坏点在初始 H 之后时已发的 `Synced(H)` 只确认旧窗口，不得伪造新 marker；**无带外 Synced**（只在真实追平 H 时发）；details 含脱敏 reason、session_id、可定位坏 seq/event_id、**last_confirmed_cursor**，不含坏行原文。
   - `EventLog.follow(session_id, after=None) -> AsyncContextManager[AsyncIterator[LogItem]]`（契约 L229-236 四步字面）：①先注册 wakeup、再在短读事务捕获 H（该读取=初始游标验证/补读窗口的线性化点）②分页补读 after.seq<seq<=H，发**一次** `Synced(cursor=EventCursor(session_id, H))` ③此后始终查 seq>last_seq，**Bus 只当唤醒信号**（注入 `VolatileBus`；`asyncio.Event` 单槽信号合并重复唤醒；**最长 1 秒轮询兜底**；TS `subscribeDurable` L830-848 `PubSub.sliding(1)` 对应）④同一连接按 seq 严格递增；补读/yield/等待期不持会话提交锁。
   - follow 只保证 durable 不回放 ephemeral；游标不可跨 session；进 read_only_diagnostic 后 typed read/follow 都报 StorageCorrupt，不能凭更大 after 或类型过滤绕过坏点（依赖 session.status 读取，经由只读 repo）。
