## 【前提修正】（TS 源码核实，记档于 parity 报告 D5 修订条）

原 D5 判断「TS 直接执行」**部分不成立**：TS 原生 shell 工具在 Windows 同样显式选 PowerShell（`packages/core/src/shell/select.ts` win() 序=pwsh→powershell→gitbash→COMSPEC；本机无 pwsh → TS 也落 powershell 5.1，与 py 默认链相同）；parity p8 的 TS 侧实际走 `execute`→lean-ctx `ctx_shell`（宿主自有 MCP 路径，非 TS core shell 工具）。p8 py 多轮纠错的直接诱因=模型写了未加引号的裸命令（`;` 裸露），该写法在 bash 下同样失败——此例非结构差。**残余真差=py 缺 TS 的显式 shell 选择面**（select.ts `resolve()` L181 config 优先级：`if (configShell) return select(configShell, ...)`）与 cmd 家族 argv 臂（args() L166 `["/c", command]`）。

## 【修复】（默认链零变化，§5.3 L276 契约钉死处不动）

1. `src/opencode/process/interpreter.py`：
   - `SHELL_ENV = "OPENCODE_PY_SHELL"`（选择面常量）；
   - `Interpreter.family` 扩 `"cmd"`；`argv()` 增 cmd 臂 `[exe, "/c", command]`（TS args() L166 逐字）；
   - `_infer_family()`：按可执行名推断家族（pwsh/powershell→powershell；cmd→cmd；其余含 bash/sh→bash，=TS args() 末臂的 sh-like 家族）；
   - `_resolve_configured(value)`：`shutil.which` 解析（PATH 名或绝对路径皆收）→ 家族推断 → 探测（cmd 臂 `[exe, "/c", "exit 0"]`）→ 失败=点名配置值的显式诊断，**绝不静默回退默认链**；
   - `resolve_interpreter(configured=None)`：config 优先（TS resolve() 语义）；缓存键含配置值（中途换值重探测不吞旧账）。
2. `src/opencode/process/__init__.py`：导出 `SHELL_ENV`。
3. `src/opencode/tools/builtin/bash.py`：`_execute` 读 `OPENCODE_PY_SHELL`（空白视为未设）；`BASH_DESCRIPTION` 披露选择面（模型可见）。
4. `tests/integration/test_tool_bash.py` 增 5 用例：家族推断矩阵（TS meta 臂全覆盖）、cmd/ps/bash 三 argv 形、**真跑选择面**（OPENCODE_PY_SHELL=sys.executable→`python -c` 语义真进程 `selected-ok-77`）、不可用值 fail-closed（点名 OPENCODE_PY_SHELL+值+no silent fallback）、无旋钮默认链逐字不变。
