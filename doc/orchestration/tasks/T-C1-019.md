**失败面（验收 C 全量——测试计划 L133 逐项落）**：
- 流中断（EOF 无终止/error chunk）→ 已收完整文本+step/run 终态 interrupted；正常取消尽量提交已收文本（§3.1 L142）；**不拼接不重发（§8 L350）——测试断言生成次数=1**。
- 重复 tool_call_id/不完整 JSON/超限 → 本次生成失败**且不执行任何工具**（§2.3 L100）；合法 JSON 但未知工具/参数不符 schema → 该调用 not_started 失败结果（tool_result 配对保持——每个合法 tool_call_id 唯一 tool_result）。

- **chunk→计划→请求回放一致性（A-006 §10 L385 S6 义务）**：本次响应产生的调用计划回放进下一次请求时与 chunk 聚合结果一致（含畸形/非点分名经 S4 透传的 not_started 失败路径回放测试——④-3 联动，T-B-019 §8-4）。
