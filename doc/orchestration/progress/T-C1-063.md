## ② 设计判定（落位 / 请求形 / ModelRef 解析 / 失败语义归属）

1. **落位**：`session/llm_summarizer.py`——适配器服务 session 层 `SummaryGenerator` Protocol、消费 `ai.provider` 缝，按「落位由研判报备」落 session 包（`session.runner` L56 已有 `from opencode.ai.provider import Provider` import 先例）；`compaction.py` 零触（引擎核心冻结，切片一裁定延续）；`ai/**` 零触（纯 provider 面）。无 import 环（llm_summarizer 仅 import compaction/context/contracts/ai 面，均为叶子）。
2. **请求形**（契约只钉 `SummaryResult` 三字段语义，形自设计）：单 user 消息 = 固定指令 + 覆盖区间**纯转写**（user 文本 / assistant 文本+推理+工具调用 name+input+state / 工具结果文本 / 文件引用只渲染 URI 不读 §2.1 L72 / idle 行含 outcome 与 error）。转写是**展示不是回放**：无需 call/result 配对、不会因未决工具部份失败（回放形 `_assemble` 会拒绝非终态工具部份）；无本地 token 预算（阈值=消息计数代理为既定裁定，token 面另议；溢出经 provider 错误 fail-closed 落 ④）。
3. **ModelRef 解析（⑥ 同源裁定）**：`settings.model`——R2 组合所有生成经 `ContextBuilder.build` 的 `model=self._settings.model`（context.py L279），摘要调用同源；`max_output_tokens`/`temperature`/`timeout_s` 同取自同一 host 注入 `RuntimeSettings`。构造面 `(provider, settings)` 是票面「以 provider+ModelRef 构造」建议的**收严泛化**：只传裸 ModelRef 会逼出无契约依据的发明默认值（output/timeout），违反 ⑥ 同源原则——在此记档供调度器过目。
4. **失败语义归属**：异常上抛——引擎 `compact()` L259 调用点传播（引擎无吞噬）→ service `_post_run_compaction` `except Exception` → `_compaction_errors[session_id]`（service.py L1348-1352），零替换零半写（§2.4 L132）；`CancelledError` 不被任何层捕获 = 关停取消语义保留。错误形三支：ErrorChunk 的 `CoreError` **verbatim**；EOF 无终块/空流 = `PROVIDER_STREAM_INTERRUPTED` retryable=True（runner L795-799 形，消息区分 "stream closed"/"empty stream"）；无 tools 请求携工具调用块 / 终块后空正文 = `VALIDATION_ERROR`（runner `_GenerationViolation` 映射先例，details.violation 携带）。`SummaryGenerationError` **不子类化 StoreError**：不跨 store/§7 拒绝缝（纯内部诊断面），且基类每类一 ClassVar code 无法承载 verbatim provider 错误。
5. **聚合细则（runner 先例对齐）**：多 `UsageChunk` 末块胜（L96）；多 `FinishChunk` 首块胜（§2.3 L102「至多一个」下防御同形）；finish reason **不门控**（逻辑 finish verbatim，runner 一致）；request_id = `compaction_{uuid4().hex}`（§2.2 caller-chosen 无前缀规则）。
