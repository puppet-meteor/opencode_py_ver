## 2. 锚映射（TS 权威 → PY 实现）

TS 权威四面（席位亲读，票面钦定三面+schema 面；均不在 `doc/source-baseline.json` 内）：`tool/plugin/websearch.ts`（~190L）+`core/src/websearch.ts`（~185L）+`config/plugin/websearch.ts`+`schema/src/websearch.ts`。

- **工具面**：TS name="websearch" → PY wire name `websearch__search`（namespace="websearch"/name="search"——builtin 双段形，webfetch 先例）；description verbatim 两段（动态年份句取当年 PY 化）；Input `{query}` 单字段（providerId=内部面不入 schema）；Output `{provider, results[]}` 非 None 字段才载（title/content/published 载而缺省——TS undefined 省略语义）；`NO_RESULTS` verbatim。
- **执行序**：Invoker 权限门（`extract_resources` query 绑定；denied→零 provider 调用直证测试）→`service.query`→**ProviderRequired→consent 流**→provider 执行→markdown 结果面。
- **consent 流映射**：TS `Form.ask` 三选项→PY 适配器模块内宿主可注入 `ConsentChannel` Protocol（`ConsentForm{session_id, header, kind, fields}`/`ConsentField{key, question, options}`/`ConsentOption{value, label}`/`ConsentReply{status: "answered"|"cancelled", answers}`）；文案 verbatim（"Web Search"/允许问句/`Allow search via {names}`/"Choose another provider"/"Disable web search"/"Choose a web search provider"/"Choose a provider for web search."）；实例级 `asyncio.Lock`（TS `Semaphore(1)` providerSelectionLock）+`asyncio.wait_for`（缺省 60s 可注入 `consent_timeout_s`）；TS 复查序保持（已解析 default()→直返；空 registry→ProviderRequired 先于 form；channel None→ProviderRequired fail-closed）；disable→`select(False)`→DisabledError；超时→cancelled 同一身份。
- **错误面 verbatim（TS mapError）**：429→`Web search rate limited (HTTP 429)`、401→`Web search authentication failed (HTTP 401)`、**他 status→泛句 `Web search request failed (HTTP {status})`（map 缺省臂）**、无 status→fallback `Unable to search the web for {query}`；RequestError 各臂 `metadata={"provider": id}`（含 statusless fallback 臂）；非 Request 错→fallback `metadata=={}`；广谱 `except Exception`→fallback（TS 同形 fail-closed）；四类 tagged PY 化（`WebSearchProviderRequiredError`/`WebSearchProviderNotFoundError`/`WebSearchDisabledError`/`WebSearchRequestError(provider_id, cause)`）；适配器层 `WebSearchCancelledError("Web search cancelled")`。
- **core 服务面**：KV 持久 selection+session 亲和+random 轮换+429 cooldown TS 语义逐面 PY 化——attempted 集+环尽回退末 cooldown 错+环内跳过不执行+显式 provider_id 忽略 cooldown（三语义全测试钉）；`cooldown_millis`：缺省/空/不可解析→60_000；有限秒≥0→×1000（负→60_000）；HTTP-date→`parsedate_to_datetime`/`fromisoformat` 双臂、naive→UTC、`max(0, date-now)`。
- **progress 面**：TS `onProvider` 回调→适配器构 `on_provider` 闭包，经 `ToolContext.progress` 每次尝试发布 `{"provider": id}`。
