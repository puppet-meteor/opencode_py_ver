4. **ToolResult.metadata 在 invoker 边界丢弃**：py.tool.finished 无 metadata wire 字段（§3.1 L131）；§5.3 L276 的 metadata 64 KiB 上限实际执行面是 py.tool.progress（bounded progress callback），不在 finished。
5. **read 单根=working_dir**：§5.1 L255 R2 唯一可用根；config 声明多根归 R3（§5.2）。
6. **同步 fs IO**：Phase-1 串行锁下阻塞读不饿死其他调用+1 MiB 窗口有界；迁移线程执行器延后（事件循环阻塞风险由串行前提背书）。
7. **§5.3 L276 三项 generation 级限额只定义未执行**：argument 64 KiB/每生成 16 调用/文本流 1 MiB 超限停止的是本次生成（报错不执行超限计划），归 runner（S6）；invoke 层执行的是 structured/progress/read 四项。
8. **非对象 input 的归类**：现为 ToolInvokeError（基础设施错，§7 L341 fail-closed）而非模型可读 failed/not_started 结果；S6 runner 接入时若模型可产非对象参数需重分类。

10. **严格 UTF-8 vs TS U+FFFD**：解码失败即 TOOL_FAILED（TS TextDecoder 以替换字符继续）；按契约 §5.3"文本文件"读法，已测。

12. **空文件渲染 `Read file {path}, 0 lines`**：TS toModelContent 对空页的措辞未逐字验证（锁指纹段未覆盖 0 行分支），低风险浮报。
