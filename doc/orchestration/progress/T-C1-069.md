## ② 设计判定（含两处裁量点与判据）

- **模块与能力门（零 `__init__.py` 编辑）**：W2 面=新建 `src/opencode/watcher/reload.py`（426 行）单文件，**不动 `__init__.py`**——W1 红线测试 `test_the_package_imports_only_the_guard_faces` 把包导入钉死为恰 {contracts.errors, storage, watcher.service} 三脸且 W1 测试文件冻结不可改；`opencode.watcher.reload` 经包导入天然先跑 W1 extras 守卫（httpapi 延迟可选先例），显式 reload 命令与 watch 服务同门（新增 extras 测试实证：无 extras 时经包导入触 `WatcherExtrasMissingError`/`UnsupportedCapability`，core 不受影响）。
- **裁定②（reload 非热重载，唯一新快照路径）**：`ReloadOrchestrator.reload()` 在 `asyncio.Lock` 内三段闭合——预检 idle → 宿主注入的 resolve 闭包（同步或异步，经 `ConfigLoader` 公共脸重解析，失败则 `ConfigError` 传播且旧 regime 原样）→ **apply 点新鲜复检**（3.2 commit-lock：resolve 期间启动的 run 被拒）→ 新快照字节重算 6.2 canonical hash（digest 绝不携带）+ `verify_snapshot_hash` 经 contracts created-data 模型往返复验 → regime 换轨。文件事件结构性不可达此路径（watcher 只提示、宿主决定）。
- **裁量点 1（新快照注入路径）**：宿主为 **reload 后新创建**的会话把 `orchestrator.current_runtime.snapshot` 传给 `SessionService.create(config_snapshot=...)`；既有会话的已录 `py.session.created` 永不回写（其快照=冻结的行为基线）。编排器自身零写面——唯一存储引用是 `ReadRepositories`，结构性写不了事件/投影行/会话记录。
- **裁量点 2（saved 决策失活载体）**：求值时 regime 门 `ReloadOrchestrator.saved_decision_is_active(*, boot_id, recorded_at)`——同 boot **且** 录于当前 regime 之下才激活（初始 regime `since=None` 上溯无穷；reload regime 自应用时刻起算，边界含）。选型依据：reload 本身零权限事件写入（裁定④）且 durable log 只追加，故失活只能是读取侧判定，不是写入侧改档。
- **裁定③（idle 三条件合取）**：①目标会话无 accepted/running/cancelling run（`non_terminal_runs` 按 §2.1 状态词汇过滤 session_id）；②**全进程**无 pending `py.permission.requested`（经 `ReadRepositories.pending_permissions()`——契约文本此处无 ① 的目标会话限定词，故取全局解读，测试钉定：目标会话空闲但别处 pending 仍拒）；③静默窗 elapsed（缺省 `DEFAULT_QUIET_WINDOW_S=2.0`，取 W1 合并窗 0.5s 之上；时钟与窗均可注入）。文件变更/命令活动（`note_file_activity`/`note_command_activity`，宿主喂）重置静默窗。观察本身只读（busy 态下 idle=False 且每行字节恒等），`check_idle` 可独立调用。
- **裁定④（boot_id/saved 衔接）**：reload 非 boot——boot_id 恒定、每条 regime 记录同 boot_id；旧 regime 的 saved 决策保留审计（行字节恒等）且新 regime 下不自动激活；他 boot 决策永不激活（5.2 轴）。零权限事件写入。
- **生命周期与回收**：模块被动（零后台任务起）；`close()`=幂等拒绝门（closed 后 reload/check_idle 拒绝）；异步上下文管理器同形。回收测试（W1 `_watcher_tasks` 前缀法扩 "reload-" 前缀）复合 WatcherService+编排器断言零残留任务。
