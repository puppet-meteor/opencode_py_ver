## ③ 未决问题（开放点浮报，调度器验收裁决）

1. **A. working_dir 来源**：采保守读法——service **构造器注入** working_dir（R1 单 service=单进程单 CWD，无 per-session 切换需求），`create` 保持 §7 表签名；App 缺省 `os.getcwd()`。备选 create 增参偏离 §7 表，未采。
2. **B. ID 生成器**：`AscendingIds` 落位 service.py（contracts 冻结）；`prefix + 13位ms + 10位counter`、精确整数数学；clock/IdFactory 可注入（FixedClock/SeqIds 钉定）。**跨进程不保证唯一**（Phase 1 单 writer 前提下成立）；clock 回拨时同 ms counter 续增保序。
3. **C. run_status 查找面**：R1=sessions.active_run_id（唯一 run 追踪面）；request_id 取自 prompt.accepted 的 **typed data**（`prompt_by_run_id`）而非 metadata；R1 无 run 历史表，非当前 active run 的 run_id→NotFound（终态化归 R4）。
4. **D. batch id**：`batch_` + ascending——§3.1 只约束事件/消息/会话/运行四类，batch id 是幂等组键，无前缀约束。
5. **E. create 通知**：采"commit→notify"对称实现（§3.2 L159 步5；无订阅者=no-op），测试阳控已覆盖。
6. **F. 错误类落位**：复用 storage wire 错误为默认；唯一例外 `SessionBusyError`——任务书 §8 基准称"storage 已导出 SessionBusyError"与实际不符（storage 包无此类），本地定义于 service.py（零 storage 新公共面）并经 `session/__init__` 导出。若审查倾向移入 `storage/txn.py`，纯移动无行为变化。
7. **fold 层不拒第二个 prompt.accepted**（任务④推荐项，**未采**，理由）：① 已并主树的 S3/S4/S6 测试依赖同 session 多个 accepted 可提交（分页测试单 session 多消息、幂等重试依赖已提交事件可查），fold 拒绝将直接破坏基线门禁；② §3.2 写门禁清单不含 run 槽——§7 L323 是服务协议级门禁，TS 对应物 publish 层 KeyedMutex 已映射到 service 层每 session 锁；③ R1 无释放槽的终态事件，fold 拒绝会把"同 request_id 幂等重试"也拦下（dedupe 查询需要已提交事件）。风险与缓解：直连 `SessionStore.commit` 的旁路可在读模型上覆盖 active_run_id——R1 单写者+服务唯一入口假设下可接受，R2 调度器落地时如需持久不变量可在 events 层加约束。
8. **SessionBusyError.retryable 沿用家族默认 False**：§8 未逐 code 钦定 retryable 值，R1 现有 storage wire 错误全部默认 False，保持一致；若裁决 SessionBusy 应为 true，子类单行覆写即可。
9. **service.close() 与任务①"drain bus/dispose engine"的调和**：按任务②释放序（service.close→engine dispose）将 engine/writer lock 所有权归组合根（engine 由 App 经 open_database 构造）——service 只释放自有资源（closed gate+锁映射）。否则"close 后 prompt→SessionClosed"不可实现（prompt 的状态读取先于 service gate，engine 若已 dispose 该语义无从谈起）；bus 为无状态唤醒面（S5/S6 定案），无需 drain。
10. **锁映射无上界**：每 session 一把 `asyncio.Lock`，`close()` 清空；R1 单进程会话数有限且 TS KeyedMutex 同为进程内映射；上界/淘汰策略留待裁决。
11. **未测跨进程窗口**：prompt 锁内 await 间隙另一实例关闭数据库——R1 单写者+单组合根假设下不构造（双开已被 WriterLockHeldError 拦截，R0-B 已测）。
12. **无契约矛盾**：与 §7 L298-325、§3.2/§3.2.1、§6.1/§6.2、r1-slices R1-S7 L134-149 逐条对齐；r1-slices L144"除非命中第 2 步幂等"括注与 §3.2.1 冲突处按任务书明示以契约为准（read_only_diagnostic 始终先拒）。
