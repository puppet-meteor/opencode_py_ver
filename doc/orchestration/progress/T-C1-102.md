## 2. 锚映射（TS 权威 → PY 实现）

TS 权威四件（席位亲读，均不在 `doc/source-baseline.json` 59 条内——指纹归调度器记档）：`tool/plugin/webfetch.ts`（222L 全读）、`tool/html-markdown.ts`（658L）、`tool/http-body.ts`、`mime.ts`。

- **常量 verbatim**：DEFAULT_TIMEOUT=30 / MAX_TIMEOUT=120（schema `maximum` 面）/ MAX_REDIRECTS=10 / MAX_RESPONSE_BYTES=MAX_MARKDOWN_BYTES=5*1024*1024 / redirectStatuses={301,302,303,307,308}；description 两段 verbatim；请求头三面 verbatim（OpenCode UA / per-format Accept q 序 / `en-US,en;q=0.9`）。
- **执行序**：scheme 门 → Invoker 权限门（先于任何 HTTP）→ 手动重定向链逐跳（status 集+location 相对解析 `urljoin`=TS `new URL(location,url)`+每跳 scheme 复断+每跳 policy 复查+MAX 10 verbatim 句）→ Cloudflare 面（403+`cf-mitigated: challenge` → UA 换 `"opencode"` 整链重试一次）→ mime 门（image 附件拒/非 textual 拒/svg+xml+vnd.fastbidsheet 豁免）→ 有界 collect（预检+per-chunk，超限 verbatim 句）→ 全链超时（`asyncio.wait_for` 覆 fetch+mime+collect；decode/convert 界外；缺省 30，超时句 verbatim）→ convert（raw content-type 不含 `text/html` → 透传；markdown → html→markdown；text → extractTextFromHTML）。
- **双权限面映射**：TS `permission.assert`（初始 URL，先于任何 HTTP）→ PY Invoker §5.1 L259 门（resources 经 `extract_resources` 绑 url）；TS `permission.assertNotDenied`（逐跳）→ adapter 自带面：宿主以 `bind(app.policy)` 绑同一 `PermissionPolicy`，每跳 evaluate 仅 `deny` 失败（ask/allow 过——重定向不重跑初始 URL 已清的审批协议；跳 `input_hash=""` 审计位，跳永不激活存档决定）。
- **机制矫正（记档）**：TS 序=scheme 先于初始 assert；PY 序=Invoker 门先于一切（宿主级门先于每个 adapter），scheme 门在 adapter 内 fetch 之前——双序同 fail-closed（网络 I/O 前双断），矫正记档不翻面。
- **输出面 verbatim**：`structured_output={url, contentType, format, output}`、content 文本==output、`metadata={"contentType": ...}`（metadata 仅在 adapter 自层 ToolResult——Invoker 终态 `ToolOutcome` 无该字段，测试经 direct execute 钉）；错误统一结构化包装 `Unable to fetch {url}: {detail}`，零裸抛零静默。

## 3. §5 披露八项

1. **html-markdown.ts 亲读结论+锚3 选型**：TS 为 658 行自有状态机，驱动 htmlparser2 token 流（无 Python 侧 1:1 对应——移植实现体需等价 token 流仿真，体量≈重写状态机，超锚"最小核心面"）→ 选 **PY 自形最小转换器，DIFFERENT-BY-DESIGN**（stdlib `html.parser` 事件流块构建）。覆盖面：h1–h6、段落、链接 `[text](href)`、fenced pre（`class="language-x"` 检出，含 pre 内嵌 code 捐赠语言、首换行丢弃、`<br>`→空格）、ul/ol+嵌套两空格缩进。**放弃面全清单**：tables/blockquotes/details/summary/images/hr/dl/内联语义标记（b/i/strong 等按纯文本透传）。为何非他形：第三方 markdown 转换库=违反 pyproject 零改零新依赖纪律；逐 token 移植=658 行级状态机非本票"最小"锚。`MAX_MARKDOWN_BYTES`=5MB 保留（code-point-safe UTF-8 字节切片=`sliceBytes` 二分语义）。
2. **http-body.ts / mime.ts 亲读结论**：`collectBoundedResponseBody` 形逐面移植（declared content-length 预检+parseInt 负值/不可解析守卫→PY `int` 失败视为未声明；per-chunk 累计越限即断；too_large 句由调用方工厂注入=句 verbatim `Response too large (exceeds 5242880 byte limit)`；流释放 finally 面，close 失败不掩原错）。`Mime.isTextual` 判据集 verbatim PY 化（空串/`text/*`/`application/json`/`*+json`/`application/xml`/`*+xml`/`application/javascript`/`application/x-javascript`；**未知 mime=拒** fail-closed）；image 附件面（`image/*` 且非 `image/svg+xml` 且非 `image/vnd.fastbidsheet`）两句 verbatim。
3. **PY policy 行形**：`_DEFAULT_EFFECTS["webfetch__fetch"]="ask"`（行级默认，S5 subagent 行先例）；`_ASK_NAMESPACES` **不触**（git-trio 先例——非命名空间级 ask 族，测试钉 `"webfetch" not in _ASK_NAMESPACES`）；`extract_resources` url 绑定（第三面，插于 path/command 之后，既有两面签名零变）。
