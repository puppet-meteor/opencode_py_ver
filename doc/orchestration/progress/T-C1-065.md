## ① 设计判定

### 富化扫描面定义（bash.py `_deny_label`，写面仅 advisory 富化）

- 扫描面 = **raw command string（既有地板，逐字保留）** ∪ **结构化分解 decoded 面**：每个 pipeline stage（`CommandSegment`）的 **joined argv**（`" ".join(segment.argv)`）+ **每个 decoded argv 项**（即 `Token.text`，变量以源形回渲染不求职）。两类遮蔽由此可达：
  - **引号遮蔽**：`rm -rf "/"`——raw 正则的尾前瞻 `(?=\s|\*|$)` 被闭引号打断漏报；decoded argv `("rm", "-rf", "/")` joined 后裸 `/` 居行尾命中。
  - **行续遮蔽**：`rm \<换行>-rf /`——raw 面 `\s+` 链被反斜杠打断漏报；解码去行续后 argv 同上命中。
- **label 优先序不变**：沿 `_DENY_HINT_PATTERNS` 元组序迭代，首个命中任一面的 pattern 定 label（`raw` 与 `decoded` 任一命中即该 label）。
- **空 Token 惰性**（T-B-076 MINOR-2 落钉）：尾随行续词产生空 argv 项（`parse_bash("echo \\\n").argv == ("echo", "")`）；空串匹配不了任何非空 deny 正则——零特判，惰性成立（`test_deny_label_empty_argv_item_is_lazy`）。
- 红线五钉全部落测：①advisory 永不 block（hit 仅前置警告文本；`echo "rm -rf /"` 无害命令照跑+advise 落集成测）；②解析失败→raw 路径逐字节不变（见回退证明）；③严格增量：新命中命令的 advisory 文本与冻结 `_ADVISORY_TEXT` 逐字节同一（字面量钉）；④`bash__run` policy 默认 ask 零变化（policy.py 零触碰；C1 冻结测试 `test_parse_outcome_never_changes_the_ask_face_or_the_advisory_hints` 原样通过）；⑤解析仅服务 advisory 面——解析异常绝不产生 `_failure`/TOOL_FAILED（`test_bash_unparsable_command_still_runs_with_raw_advisory`：解析失败命令正常执行、tool succeeded）。

### 解析失败回退证明（invariant ②）

`_decoded_scan_surfaces(command)` 内 `try: parse_bash(command) except Exception: return ()`——ShellParseError 或解析面任何异常一律空面集；`_deny_label` 随后仅以 `(command,)` 单面迭代，与富化前实现同序同判（raw floor 行为逐字节不变，fail-open 到现状而非到无提示）。落测：`test_deny_label_parse_failure_keeps_the_raw_regex_path`。

### PS IR 复用-or-扩展判定：**全复用，零扩展**（ir.py 零触碰，写面收窄为 3M+4A）

- `QuoteKind.SINGLE`/`DOUBLE` 语义 1:1 承载 PS 单引号（字面）/双引号（$var 展开语义）；**转义符差异（反引号 vs 反斜杠）在解码时完全吸收**（escapes 落 `LiteralPart.text`），IR 无需承载；`StatementSeparator` 的 `&&`/`||` PS 永不产生（PS7 pipeline-chain 归入 unsupported 清单）；`PowerShellCommand = BashCommand` 纯别名（powershell.py 内定义，不动 ir.py）。
- **错误码族：七码全复用，零新增**（PS 特有拒绝全部映射 `unsupported-construct`；闭集测试同步钉七码）。

### PS unsupported 显式拒绝清单（起草，「fail-closed 优于近似」）

子表达式 `$(...)`（含双引号内插值形）、数组表达式 `@(...)`、哈希表字面量 `@{...}`、splatting（词首 `@name`）、脚本块 `{...}`、类型字面量与索引 `[...]`、逗号数组 `,`、保留符 `<`、call 操作符 `&`、pipeline-chain 操作符 `&&`/`||`、非纯形 `${NAME}` 之外的花括变量（含 `${name:x}`、`${1}`）、后随空段的 `|`。正则 `` `u{...}`` 经 `{` 走脚本块拒绝（无独立诊断，④ 已浮报）。

### bash ↔ PowerShell 同形差异表（转义/引号/变量）

| 语法面 | bash（C1） | PowerShell（C2） |
|---|---|---|
| 转义符 | `\`（词外全转义；双引号内限 `$ \` `` ` "`` 四名） | 反引号 `` ` ``（任意字符一律转义；`` `n `t `r `b `f `v `a `0 `` →控制字符，`` `e ``→ESC[PS6+]） |
| 行续 | `\<newline>` | `` `<newline> `` |
| 单引号内 `''` | 相邻部件：`'it''s'` → `it`+`s` 两 parts | PS 加倍：`'it''s'` → 单 part 文本 `it's` |
| `$` 家族 | `$NAME` `${NAME}` + specials `@ * # ? $ !` + 数字位参 `$1` | `$NAME` `${NAME}` + `$?`（唯一 automatic 变量）；数字/其他 specials 字面（`$1`→`"$1"`） |
| 语句分隔 | `;` `&&` `||` newline | `;` newline（`&&`/`||` 拒绝） |
| `;;` | case 终结符 unsupported | 第二个 `;` → empty-command |
| `&` | 后台操作符 unsupported | call 操作符 unsupported |
| `<` | 重定向算子族（heredoc/proc-sub 单独拒） | 保留符直接拒 |
| `|` 换行续 | 消费 `\s+`（含换行） | 同形（PS 隐式续行落正例 golden） |
| 词内特殊符 | `#` 词中字面；`( ) { } [ ] ,` 词字符/近似 | `#`/`@` 词中字面；`( ) { } [ ] , < >` 断词并 fail-closed |
| `$'..'`/`$".."` | 拒（bash 特有形） | 不存在于 PS 语法（天然不触发） |
