## ③ 不可达·防御分支清单（任务⑥ 强制浮报，B §8-3 定案条款）

【协议不可达】（需违反协议前提才可达）

2. `_map_chunk` 末尾 `choice.finish_reason` 二次赋值：重复 finish 帧在同函数顶部 L86 拒绝块（duplicate_finish）先行失败整流，赋值仅首个 finish 可达（行内注释钉定）。

【未测防御】（合法路径但本切片无测试覆盖）
3. 5xx→ProviderUnavailable retryable=True 不自动重试（OP-8 保守读法）：fake server 可注入（status=500）但方案④测试清单未列——行为待 OP-8 终审后补钉（④-2）。
4. 连接建立失败重试（APIConnectionError cause=ConnectError/ConnectTimeout→`_RetrySignal(None)`）：重试集第二成员（429+连接建立失败 §8 L350），fake server 未注入 connect-refused——重试机制以 429 路径钉定，connect 分支未测。
5. create() 阶段 `openai.APITimeoutError` 分支（httpx2 read/write/pool 超时源）：测试 header 超时走 asyncio.timeout→TimeoutError 分支；两分支产出同一 header 超时失败，仅异常源不同。

8. `retry_after_seconds` 边角：负 ms 值回落秒数头、无效秒数→None、HTTP-date 形态（有意不实现 §6-5——按无效处理等待 0）：单元覆盖 ms 优先/无效 ms 回落/负秒/空表，余未测。

10. `_map_finish_reason` length/filter/unknown 三映射：golden 覆盖 stop/tool_calls，其余词汇表成员未测。
11. `stream()` 重试决策处 remaining≤0（"total deadline exceeded before retry"）：截断测试的 deadline 命中在读循环，本分支（429 到达即耗尽预算）为近重复防御。
