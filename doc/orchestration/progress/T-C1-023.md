## ① 方案审视发现

1. **escape 规则选型**：模块级 `str.maketrans` 单表——C0（除 `\t`/`\n`）+ DEL（U+007F）+ C1（U+0080-9F）→ U+FFFD。确定性纯函数、零正则、可枚举单测；ESC 被替换即使 CSI 序列整体消解（e2e 钉定）。
2. **终态判定接缝**：一律以 `service.run_status` 轮询（`_POLL_INTERVAL_S=0.05`）为唯一权威；Bus 订阅仅预览——`SlowConsumerError` 只降级显示（stderr 一行）不改终态判定与退出码；终态后 `_DRAIN_S=0.2s` 排空打印机再取消任务，避免半行。
3. **订阅时序论证**：`bus.subscribe(session_id, _PREVIEW_TYPES)`（六事件白名单）先于 `service.prompt` 进入（async with 先开订阅、打印机 task 先起，再发 prompt）——早事件不丢；终态排空后才 cancel 打印机。
4. **REPL 行为选型**：行读取 `asyncio.to_thread`（事件循环不阻塞）；`_EndOfInput` 在**线程函数内**转换 `StopIteration`/`EOFError`（PEP 479 危险点）；空行→再提示；`/exit`/EOF→0；prompt 面 Ctrl-C→130；`/history [limit=50]` 前向翻页（每页 ≤100、clamp 1..1000 沿 repos 面）；运行中 Ctrl-C→`service.cancel(run_id)` 幂等重复、持续等待终态**不硬退**（保护清理不变量 §7 L337）；REPL 不因 failed/interrupted 轮次退出（仅 cleanup 失败→3）。
5. **迁移发现顺序**：cwd 向上找 `alembic.ini` → 回退包位置 `parents[2]`；subprocess `[sys.executable, "-m", "alembic", "-x", "db_path=<db>", "upgrade", "head"]`（沿 test_service_run.py `_upgrade_head` 形态）；失败=stderr 原样透出+exit 70，不吞。
6. **单 active run 不变量**：REPL 每轮 `await` 终态后才读下一行——同 session 永不并发 prompt，busy gate 在 CLI 面协议不可达（见 ③）。
7. **PY_\* 常量导入面**：`opencode.contracts/__init__` **不**再导出 PY_\* 事件类型常量（仅子集）——cli.py 初版从 `opencode.contracts` 导入被 mypy attr-defined 抓出，改为自 `opencode.contracts.events` 导入（沿 runner.py/test_runner.py 既有 idiom），运行期同构。
