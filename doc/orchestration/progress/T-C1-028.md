# T-C1-028 进度记录（R3-S4 write/edit：精确冲突检测+原子替换）

## ① 方案审视发现（选型论证）

- **edit.py = edit.ts 332L 冲突检测核心的直接移植**（任务书④锚，逐函数语义对应）：`normalizeForMatch`（typographic 引号/破折号/空格变体——Python 以 `str.translate` 1:1 平移表实现，避免链式 replace 的二次替换假阳性）、`findOccurrences`（精确跨度，非重叠推进）、`findLineOccurrences`（尾随换行容错的整行候选+**重叠去重**）、`lineEnding`（区域主导行尾）、`withRegionEndings`+`alignLines`（LCS 对齐复用被匹配区域的行尾）、`matchView`+`countBefore`（在 Read 展示的 LF 视图上匹配、经 `bisect_left` 把偏移映回含 `\r` 的原字节）、`endingsOnly` 模式（old/new 仅 `\r` 差异=改行尾本身，作用于精确字节）。失败措辞逐一对应 edit.ts：identical old/new、空 oldString、"Could not find oldString"、"Found N matches … expected exactly one"、unchanged 报告族、"File not found"、"Path is a directory, not a file"。
- **write.py**：`_atomic_replace`（§5.3 L274 同目录临时文件+原子替换）为两工具共享（edit.py import 复用）；目标解析把 R0-B 严格 realpath 方案**扩展到创建目标**——已存在目标走 read.py `_resolve_within_root` 原路径；不存在目标对"最深已存在祖先"做严格 realpath+对 realpath 后根做包含检查+尾部纯组件追加（尚不存在的组件不可能为符号链接；§5.3 L275 明示并发替换链接竞态不在保证内）。
- **file-diff.ts 不移植**（任务书④"仅参照"点的裁决）：TS 侧 fileDiff 产物只流向两处——`permission.assert` 的 `metadata.files` 审批预览与 Output.files 结构化输出。Python 侧 S2 审批通道（`py.permission.*` 事件+PermissionRequest）**不携带 metadata.files 面**（冻结契约，§5.2/§7 无此字段），且读四件套先例=纯文本 ToolResult（无 structured_output 消费方）——移植即无消费者死代码。不移植，记为已量化偏差而非缺陷（④ 未决点 3 留重启条件）。
- **write 无"冲突检测"面**：write.ts 本体即无条件覆盖（readText→writeText，无旧内容比对；TS 冲突语义全在 edit 侧）。§5.3 L274"对读到的版本做冲突检测"由 **edit 的全档冲突检测 + 两者共用的原子替换**联合满足——write 的"精确"体现在字节精确落盘（round-trip 测试钉）。
- **已量化偏差**（TS 有 Python 无，全部浮报）：BOM 不管理（write.ts `Bom.split/join` 保留 BOM——Python `fs__read` 不剥 BOM，`\ufeff` 在两侧均为普通文本，行为自洽）；formatter 钩子（无 Python formatter 服务面）；无文件锁（Phase-1 串行执行面+`endings_only`/字节数上限界定了每次调用成本）；`external_directory` 审批不移植（TS `FileAccess.authorizeExternal` 面——Python 根边界即 §5.3 L275 拒绝越界，无"根外仍可变更"能力，该通道无对应语义）。
- **限额（必答 2）**：`WRITE_MAX_BYTES` = 1 MiB、`EDIT_MAX_SOURCE_BYTES` = 1 MiB。TS 锚无值可对齐（write.ts/edit.ts 均无大小检查）；取值依据=§5.3 L272 读窗口 1 MiB——模型经 `fs__read` 至多见过 1 MiB，故写回/编辑的内容始终可完整读回（PHASE1-SLIM §4 L91"超大文件有诊断"的 Python 侧安全面；三件套 1000 硬帽同一先例：TS 无锚时 Python 侧量化+浮报）。§5.3 L276 64 KiB 参数流上限仍先拦正常路径，此为防御背帽。
