5. **调度器台账口径（nit-3 对应，记录级）**：format 门禁绝对值含环境本地成分（worktree 磁盘非 .venv 的 .py 恰 102 而 `ruff format --check .` 报 293——其计数宇宙超出 tracked 面 ≥191 文件；四路复现同值故本票台账一致性不受影响，但绝对值跨机/跨环境不稳——R4-S2 期 ledger 288[C worktree] vs 289[调度器 main] ±1 漂移与此同源）。建议范围限定（如 `ruff format --check src tests tools` 或 `$(git ls-files '*.py')`）以稳台账绝对值；门禁判定面（退出码 0）不受影响。

## §4 nit 清单

- **nit-1（resolve_runtime_v3 双载链读）**：`resolve_runtime_v3` 先 `resolve_runtime()`（内含链读）再 `_mcp_server_refs()`（`self.load()` 二次链读）——boot-only 单线程无正确性影响，docstring 已披露（single-threaded boot act 无交错）；S4/S5 激活时可合并为一次读取。纯效率注记，不阻并入。
- **nit-2（mcp namespace 单向固定）**：`register_mcp`/`replace_mcp_server` 强制 ns=mcp，但 plain `register()` 不拒 namespace="mcp" 占用——今日无害（异 server 同名/裸注册被 MCP 替换均已具名拒、mcp ask 默认 R3 即有、S5 接线只走 register_mcp），占用法下 ownership 查询 fail-closed 报「no owning server」；一行保留检查即闭合（§3-4，S5 硬化候选）。
- **nit-3（format 门禁绝对值口径）**：293 复现精确（B 独立跑=调度器=C×2 四路同值、退出码 0）但计数宇宙含环境成分（非 .venv 磁盘 .py=102<293）——绝对值跨环境不稳（R4-S2 期 288/289 ±1 漂移同源）；调度器口径记录级改进（§3-5），非 C 交付缺陷（C 如实执行标准门禁命令并逐字记录输出）。
